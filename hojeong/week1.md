git : 코드 변경점 기록, 버전/형상 관리 도구, 소프트웨어의 변경사항을 체계적으로 추적 및 통제
github : 온라인 백업, 공유, 협업을 위한 온라인 코드 저장소
git add : 저장할 파일을 지정하는 명령어
git commit : 실제로 저장하는 명령어
git status : 어떤 파일이 변경/지정되었는지 변경 상태를 확인하는 명령어
git branch 브랜치명 : 브랜치를 만드는 명령어
git switch/checkout 브랜치명 : 브랜치를 이동하는 명령어
git switch -c 브랜치명, git checkout -b 브랜치명 : 브랜치를 만들면서 이동하는 명령어
git merge 합칠 브랜치명 : 브랜치를 합치는 명령어
